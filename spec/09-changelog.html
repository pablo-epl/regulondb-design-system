Changelog

What changed and when. Versioned by Semantic Versioning. Tokens are a public API — their renaming or removal is a breaking change.

v1.0.0 — 2026·04 — first release

  • Foundations — Color, type, spacing, radii, shadow and motion tokens locked. tokens.json declared as the single source of truth.
  • Conventions — Scientific nomenclature encoded as components (<Gene>, <TaxonName>, <SigmaFactorLabel>, <PromoterPositionLabel>).
  • Atomic Design — Library reorganised into atoms / molecules / organisms / templates / pages.
  • Evidence palette — Curated / Predicted / High‑throughput / Weak with 12% bg + AA fg. Color-never-alone rule introduced.
  • Three deliverables — spec/ (HTML manual), lib/ (Storybook source), lib/showcase.html (single-file React preview).
  • Dark mode — semantic remap, accent preserved, postit inverted to readable yellow tint.
  • Accessibility — Lighthouse A11y >= 95 budget; axe zero-critical budget; keyboard map documented.

Migration from prototype (Feb·2026)

Components named regulondb/styles.css in the original prototype are still compatible — tokens.css names were preserved. The --font-serif token was renamed to --font-citation for explicitness. Add a temporary :root { --font-serif: var(--font-citation); } alias if migrating gradually.

v1.1 — Brand mark

  • Logo — canonical SVG (full wordmark, on-dark variant, compact mark) at spec/assets/logo*.svg and React <Logo> atom in lib/src/components/atoms/Logo.tsx. Replaces the placeholder R/M square in every consumer (spec sidebars, showcase, lib Header, prototype).

v1.2 — Summary history page

  • StatCardWithDelta (molecule) — metric tile with current value + signed delta vs a reference release. Tone auto-from-sign; override via prop. Zero deltas render as "unchanged since vN".
  • ReleaseHighlight (molecule) — color-coded one-liner banner; tones reuse the evidence palette (feature / data / structural / note).
  • ReleaseTimeline (organism) — vertical chronological list with major-release dots for x.0 versions.
  • GrowthChart (organism) — hand-rolled SVG line / stacked-area chart; no deps; supports milestone annotations and a custom legend.
  • SummaryHistoryTemplate (template) — sidebar timeline + main chart+table + right rail layout.
  • SummaryHistoryPage (page) — cross-organism release-history dashboard. Wired into the prototype at #/summary-history (no organism prefix). Backed by an extended D.releases with per-release stats across E. coli, S. enterica, and B. subtilis.

v1.3 — Assistant

  • TypingIndicator (atom) — three-dot bounce shown while the assistant composes a reply; honours prefers-reduced-motion.
  • LevelPicker (atom) — segmented audience-tunable toggle (PI / Postdoc / Undergrad / Public). Drives the per-page explainer body swap; mirrors tabs--segmented styling.
  • ChatMessage (molecule) — bubble + avatar + body; three roles (user, assistant, system). Footer slot for citation chips.
  • ChatComposer (molecule) — auto-growing textarea (max 180px) + Send + suggestions strip. Enter submits, Shift+Enter newline.
  • CitationChip (molecule) — pill linking back to the source object using ObjectTypeTag color codes; makes assistant answers auditable.
  • ChatPanel (organism) — slide-in right drawer hosting a ChatMessage list + ChatComposer. Focus-trapped via the existing useFocusTrap hook; auto-scrolls on append. Hosts the RAG chat surface.
  • ExplainerPanel (organism) — page-side variant for the per-page explainer. Mounts near the top of object pages; level choice persists in localStorage.
  • Prototype wiring — FAB launcher (.assistant-fab, bottom-right) + ⌘J / Ctrl+J shortcut. Per-page explainer mounted on gene / TF / regulon pages with curated PI / Postdoc / Undergrad / Public bodies. Engine in regulondb/assistant.js; UI in regulondb/assistant-ui.js.

v1.4 — Comparative + FAIR

Materialises three Roadmap items: the multi-genomic differentiator (M-2 Pan-regulome), a citable comparative metric (M-4 RRI), and the FAIR landing page (Q-7 + D-1..D-7).

  • ScorePill (atom) — 0–1 metric pill with a colored band reflecting the value (low / medium / high / extreme). Used by the RRI leaderboard and by the regulon page header.
  • DOIBadge (atom) — citable identifier rendered next to releases and dataset cards; click opens doi.org in a new tab.
  • ConservationCell (molecule) — one cell of the pan-regulome grid; four states (conserved / divergent / absent / unknown) with tooltip carrying the regulator symbol.
  • DatasetCard (molecule) — Card variant composing DOIBadge + format Tags + Download / Cite buttons; one card per citable artefact.
  • Pan-regulome page (organism, route #/pan-regulome) — orthogroup × organism pivot table with KPIs, function/state filters, TSV export.
  • RRI Leaderboard page (organism, route #/rri-leaderboard) — regulons ranked by Regulatory Rewiring Index with target / regulator breakdown and per-row "why" prose.
  • Datasets & Downloads page (organism, route #/downloads) — responsive grid of DatasetCards (D-1..D-7); each carries a Zenodo DOI and a one-click citation copy.
  • Per-regulon RRI pill — the same ScorePill also appears in the regulon page header meta row, linking back to the leaderboard.
  • Mock data extensions in regulondb/data.js: pan_regulome (~30 orthogroups across 3 organisms with regulator/evidence/effect per cell), rri_table (12 regulons with RRI / targetRRI / regulatorRRI / summary), datasets (D-1..D-7 with mock Zenodo DOIs).
