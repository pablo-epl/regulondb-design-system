Focus visibility

Every interactive element shows a 2‑layer focus ring: 0 0 0 2px var(--surface-canvas), 0 0 0 4px var(--blue-3). The double layer ensures the ring is visible on any surface. In dark mode the second layer becomes --blue-4 for contrast.

Color-blind safety

  • Activation vs repression — never color-only. Always paired with a glyph (→ activation, ⊣ repression).
  • Evidence categories — never color-only. Always paired with the code text (IDA / IEA / HT…) and a tooltip with the long phrase.
  • Network edges — line style differs by category (solid / dashed / dotted) regardless of color.
  • Conservation matrix — numeric % identity always rendered alongside the cell color.

Reduced motion

Under prefers-reduced-motion: reduce the system disables every transition and animation globally via tokens.css. Specific overrides also handled:

  • Drawer / dialog — cross-fade instead of slide.
  • Theme toggle — instant.
  • Skeleton shimmer — replaced by a static surface.
  • Spinner — static rotational state.

Skip-to-content & landmarks

Every page exposes a .skip-link as the first focusable element, plus standard landmark roles: banner (header), navigation (primary nav), main, contentinfo (footer), complementary (sidebars).

Verification

  • Lighthouse Accessibility >= 95 on every spec page.
  • axe-core run inside Storybook — zero critical errors per story.
  • Manual keyboard pass on Home, Gene, TF, Compare, Search.
  • Screen reader pass (NVDA + VoiceOver) on Gene araC page.
