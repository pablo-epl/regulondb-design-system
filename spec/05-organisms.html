Organism · Assistant

ChatPanel · ExplainerPanel

Two assistant surfaces. ChatPanel is the slide-in right drawer that hosts the RAG chat — open-ended Q&A with citations back to curated objects. ExplainerPanel is the page-side variant for the per-page explainer.

ChatPanel anatomy
  • Header — sparkle + title + subtitle slot + close.
  • Messages — ChatMessage list, auto-scrolled to bottom on append.
  • Composer — ChatComposer molecule pinned to the bottom; suggestions row above the textarea.
  • Behaviour — focus-trapped while open, Esc closes, body scroll is not locked, overlay is fully transparent (no dim, no backdrop blur) so the page beneath stays visible and interactive. The panel is a side drawer, not a modal.
  • Trigger — floating .assistant-fab bottom-right + ⌘J / Ctrl+J shortcut.
ExplainerPanel demo
✦About araC

araC codes for AraC, the regulator of L-arabinose catabolism. Without arabinose AraC represses araBAD via a DNA loop. With arabinose it activates araBAD, araE and araFGH; CRP-cAMP is required for full activation.

genearaC tfAraC regulonAraC

Do

Mount the ExplainerPanel near the top of object pages so the audience-tunable summary is the first thing a non-expert reads. Persist the level choice in localStorage — it’s a viewer preference, not a route concern.

Don’t

Don’t blur lines between the two panels. If the user wants a conversation, route them to the ChatPanel via the “Open in chat” button. The explainer is a one-shot summary, not a dialogue.

Organism · Comparative

Pan-regulome · RRI Leaderboard · Datasets & Downloads

Three cross-organism surfaces that materialise the multi-genomic story. Pan-regulome is the orthogroup × organism × regulator pivot. RRI Leaderboard ranks regulons by how rewired they are (M-4). Datasets & Downloads is the FAIR landing page where each artefact ships with a Zenodo DOI and a one-click citation.

Pan-regulome anatomy
  • KPIs — counts: total orthogroups, conserved-across-all, divergent-in-≥1, organism-specific.
  • Toolbar — filter by functional category (DNA repair, virulence…) + filter by state. Export TSV.
  • Legend — explains the four ConservationCell glyphs upfront, before the first row.
  • Body — one row per orthogroup, one column per organism. Each cell is a ConservationCell molecule + the regulator symbol + evidence/effect microcopy.
  • Route — #/pan-regulome (cross-organism, no organism prefix).
RRI Leaderboard anatomy
  • Header — defines the score: 0 = conserved core, 1 = wholly rewired. Variants RRI-target / RRI-regulator.
  • Legend — the four ScorePill bands (low / medium / high / extreme) with example values.
  • Table — sortable rows (default desc by RRI). Columns: regulon, reference organism, RRI, RRI-target, RRI-regulator, "Why" (one-line explanation).
  • Per-regulon pill — the same ScorePill is also rendered in the meta of each regulon page header (links back to this page).
  • Route — #/rri-leaderboard.
Datasets & Downloads anatomy
  • Grid — responsive auto-fit grid of DatasetCard molecules, min 360px per column.
  • Card actions — primary Download + ghost Cite this release (copies BibTeX-style citation to clipboard).
  • DOIBadge — every card carries a Zenodo DOI; clicking opens doi.org in a new tab.
  • Format Tags — serialisations (TSV / JSON-LD / RDF Turtle / BigWig / MEME …) rendered as neutral Tags, not ObjectTypeTag (formats aren’t biological objects).
  • Route — #/downloads.

Do

Treat the pan-regulome page as the single source of truth for "is this multi-genomic". Every other comparative surface (TF compare page, regulon RRI pill, conservation tab) should derive its numbers from the same matrix.

Don’t

Don’t hide the RRI score behind a tooltip on the regulon page. The pill belongs in the meta row next to "Members" and "Evidence" so reviewers see comparative depth at a glance.
