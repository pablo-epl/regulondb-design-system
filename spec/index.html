RegulonDB MG · v1.0

The visual contract for RegulonDB’s multi‑genomic era.

RegulonDB has been the curated reference for transcriptional regulation in Escherichia coli K-12 since 1991. Its evolution to RegulonDB MG extends curation to Salmonella enterica, Bacillus subtilis, and additional bacterial models — weaving experimental evidence and computational predictions, orthology, metabolic context, and high-throughput datasets into a single multi-organism platform. This document is the brand’s working visual contract: tokens, conventions, components, and the rules that bind a curator’s page, a CLI tool, and a conference poster to the same identity.

Five non‑negotiables

  1. Blue is the brand. Accent is rare and intentional — only on Compare CTAs, divergent gene arrows, predicted-evidence badges, and a single hero accent.
  2. Color is never the only signal. Every evidence badge carries a code (IDA, IEA), every regulation arrow carries a glyph (→, ⊣).
  3. Scientific typography is rigid. Genes are italic, proteins are roman, species are italic, σ factors use Unicode superscripts, promoter positions use Unicode minus.
  4. No decorative imagery. The brand’s imagery is data: hand-drawn SVG genome maps, regulon radials, conservation matrices — never AI illustrations or stock photos.
  5. One source for tokens. tokens.json → tokens.css → Tailwind → showcase. Anything else drifts.
