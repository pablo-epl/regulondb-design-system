Summary history

Release-history dashboard. Stat cards (with deltas) at the top, growth chart over time, vertical release timeline, per-release stats table, right rail with "About / Export / Latest highlight".

SummaryHistoryTemplate · cross-organism (no organism prefix) · route #/summary-history

New primitives this page introduces:

  • StatCardWithDelta (molecule) — value + label + signed delta vs a reference version. Tone auto-derived from sign; override via tone prop.
  • ReleaseHighlight (molecule) — color-coded one-liner banner using the evidence palette (feature / data / structural / note).
  • ReleaseTimeline (organism) — vertical chronological list with major-release dot styling for x.0 versions.
  • GrowthChart (organism) — hand-rolled SVG line / stacked-area chart, no deps. Optional milestone annotations.
  • SummaryHistoryTemplate (template) — 3-column layout: timeline (sidebar) + chart+table (main) + about/export rail.
