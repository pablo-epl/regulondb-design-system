Atoms

Indivisible primitives. They never know about the biology — with four exceptions: Gene, TaxonName, SigmaFactorLabel, PromoterPositionLabel. Those are atoms because they encode a typographic rule that cannot be re-derived from a generic span.

Atoms · Assistant

TypingIndicator · LevelPicker

Two assistant primitives. TypingIndicator is the three-dot bounce shown while the assistant composes a reply. LevelPicker is the audience-tunable segmented toggle that drives the per-page explainer (PI / Postdoc / Undergrad / Public).

Specimens
TypingIndicator — honours prefers-reduced-motion
LevelPicker — mirrors tabs--segmented styling.

Do

Use TypingIndicator to signal pending agent work. Pair LevelPicker with state, not query strings — level is a viewer preference, not a route concern.

Don’t

Don’t reach for a generic Spinner where TypingIndicator fits — the bouncy dots are the brand cue for “agent thinking”.

Atoms · Comparative

ScorePill · DOIBadge

Two primitives that make comparative + FAIR signals legible. ScorePill is a 0–1 metric pill with a colored band reflecting the value — used by the Regulatory Rewiring Index (RRI) and any other compact metric where the visual cue matters as much as the number. DOIBadge is the citable identifier rendered next to releases and dataset cards; clicking opens doi.org in a new tab.

ScorePill bands
RRI0.08 RRI0.34 RRI0.62 RRI0.95
DOIBadge
DOI10.5281/zenodo.10874321 Zenodo10.5281/zenodo.10874322

Do

Use ScorePill for any 0–1 ratio: RRI, conservation %, prediction confidence. Default thresholds (0.25 / 0.55 / 0.80) keep colors consistent across pages; override via the band prop only when the metric needs a non-default cut.

Don’t

Don’t use ScorePill for raw counts — the bar conveys "fraction of a maximum", which is meaningless for "47 datasets". Use a Tag or plain monospace number instead.

Atoms · Scientific

Gene · TaxonName · SigmaFactor · PromoterPosition · OperonNotation · ProteinSymbol · Coordinate

These four-plus atoms are the brand’s scientific contract. Their existence as components — not raw spans — is what guarantees the rules are actually applied.

Do

Use the typed components in the React lib (<Gene/>, <TaxonName/>) so the rules are enforced by the type system.

Don't

Manually italicize gene names with inline style. The class attribute is required for accessibility, search and i18n.
