01 · Foundations

Foundations

Color, typography, spacing, radii, shadow and motion. The unalterable layer of the system. Every component above this layer must compose from these tokens — never their hex equivalents.

Foundations · Color

Color

Five blues, five greys, plus four reserved hues: error red, accent gold, accent-light gold and post‑it yellow. The accent is rare and intentional. Color is never the only signal of meaning.

Color scheme — semantic mapping (light)

Each role binds a hex value. Do not bind components to raw hex; bind them to semantic tokens. Dark-mode counterparts swap surfaces and lighten primaries; the accent never dims.

A discrete dot color per biological object type. Used in ObjectTypeTag and as the icon stroke color. Distinct from the brand palette: these don’t live in components, only in lists/tables of mixed object types.

Do

Use accent only on Compare CTAs, divergent gene arrows, predicted-evidence badges, and a single hero accent. Three places per page is the limit.

Don't

Use accent as a substitute for blue when you "want some warmth." It dilutes its meaning and breaks the contract that orange = predicted/divergent.

Foundations · Typography

Typography

Arial is the workhorse. Times New Roman is reserved for citations. Courier New is reserved for sequence, code and coordinates. Sizes come from the official PDF: 24 / 22 / 20 / 18 for headings, 16 for relevant body, 14 for normal body.

Do

Use citation type only inside reference lists and inline (Author, year) citations. Use mono for sequences, IDs and coordinates. Use Arial everywhere else.

Don't

Use Times for body copy "to feel scientific", or use mono inside paragraphs. Mixing typefaces inside a sentence dilutes their semantic load.

Foundations · Brand mark

Logo

Three variants — full wordmark for light surfaces, on-dark variant for blue-1 / dark backgrounds, and a compact mark for tight spaces. The arrow always points right and is always ‑-blue-2 (or ‑-blue-3 on dark). The wordmark sits flush against the arrow tail; the italic DB sits inside the head.

Minimum size · clearspace

Minimum height 22 px for the wordmark, 16 px for the mark. Maintain clearspace equal to the height of the ‘R’ on every side.

Programmatic usage

React (lib/)
import { Logo } from "@regulondb/ui";

<Logo variant="wordmark"      height={32} />        // light surface
<Logo variant="wordmark-dark" height={28} />        // on --blue-1 (header)
<Logo variant="mark"          height={24} />        // narrow / favicon
Static HTML / spec
<img src="assets/logo.svg"          alt="RegulonDB" height="32" />
<img src="assets/logo-on-dark.svg"  alt="RegulonDB" height="32" />
<img src="assets/logo-mark.svg"     alt="RegulonDB" height="24" />

Do

Use the on-dark variant over --blue-1. Keep clearspace ≥ x-height of the “R”. Use the compact mark only when the wordmark falls below 22 px tall.

Don't

Recolor the arrow to anything other than --blue-2 / --blue-3. Stretch, skew, rotate, drop-shadow or place over busy imagery. Pair it with a different typeface for “DB”.

Foundations · Motion

Motion

One easing curve, three durations. 120ms for color/border swaps, 200ms for drawers and dropdowns, 320ms for page transitions. Honour prefers-reduced-motion.
